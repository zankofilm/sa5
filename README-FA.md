# مدرسه‌یار — Android V1.5 اصلاح پنجره شروع آزمون

این نسخه بر پایه سورس اندروید تأییدنشده V1.4 ساخته شده و تنها مشکلی را که در اسکرین‌شات گزارش شده برطرف می‌کند: دکمه «شروع آزمون» در پنجره جزئیات آزمون زیر نوار پایین اپ پنهان بود.

## دلیل خطا

در نسخه وب موبایل، `mobile-p28.css` برای نوار پایین `z-index:999!important` تعریف می‌کند، اما پنجره جزئیات آزمون در `styles.css` فقط `z-index:40` دارد. بنابراین نوار پایین از روی پنجره می‌گذرد و دکمه اصلی انتهای پنجره را می‌پوشاند.

## اصلاح V1.5

- پنجره‌های باز روی نوار پایین قرار می‌گیرند.
- وقتی «شروع/ادامه آزمون» ظاهر شد، **همان دکمه اصلی** با حفظ رویداد کلیک در یک نوار شناور پایین پنجره قرار می‌گیرد.
- صفحه جزئیات آزمون قابل اسکرول است و نوار پایین هنگام نمایش این پنجره موقتاً پنهان می‌شود.
- با بستن پنجره، نوار پایین باز می‌گردد. برای هر آزمون دیگر نیز دکمه صحیح همان آزمون نمایش داده می‌شود.
- داده‌ها، پاسخ‌ها، زمان‌بندی، کد اختصاصی برگه و ارتباط با سرور تغییر نکرده‌اند.

## روش نصب

از بسته «PATCH» فقط محتویات زیر را با حفظ مسیر در GitHub جایگزین کنید:

- `app/src/main/assets/girl-sections.css`
- `app/src/main/assets/girl-sections.js`
- `app/build.gradle`
- `tests/exam-intro-overlay-v15.test.mjs` (آزمون اختیاری)

سپس در GitHub Actions، APK جدید را بسازید. لازم نیست چیزی روی سرور مدرسه نصب شود. **پیش از حذف APK قبلی، هر پاسخ امتحان آفلاین/پیش‌نویس را در نظر بگیرید؛ حذف برنامه داده‌های محلی آن را پاک می‌کند.**

## تست روی گوشی

1. در بخش آزمون‌ها، روی آزمون دانلودشده ضربه بزنید.
2. در پنجره اطلاعات باید دکمه واضح «شروع آزمون» یا «ادامه آزمون» در پایین نمایش داده شود و با نوار ناوبری تداخل نداشته باشد.
3. اگر قصد شروع واقعی دارید، تنها با یک آزمون **آزمایشی** دکمه را بزنید تا صفحه سؤال‌ها باز شود. برای آزمون رسمی زنده بدون هماهنگی روی دکمه شروع نزنید.
4. پنجره را ببندید؛ نوار پایین باید بازگردد.
5. سایر قسمت‌ها مانند داشبورد، تکلیف و چت را بررسی کنید.

آزمون‌های Node در مخزن قابل اجرای خودکارند؛ رندر این اصلاح در مرورگر شبیه‌سازی می‌شود. عملکرد واقعی APK هنوز باید روی گوشی شما تأیید شود.
